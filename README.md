## 🚀 شروع سریع

### پیش‌نیازها

- ✅ **Python 3.11+**
- ✅ **Xray-core** (به‌صورت خودکار نصب می‌شود)
- ✅ **توکن ربات تلگرام** (از [@BotFather](https://t.me/BotFather))
- ✅ **توکن گیت‌هاب** (برای ذخیره‌سازی)

### نصب

```bash
# ۱. کلون کردن ریپو
git clone https://github.com/hivaasadi8/HiVoConfigs.git
cd HiVoConfigs

# ۲. نصب وابستگی‌ها
pip install -r requirements.txt

# ۳. تنظیم متغیرهای محیطی
export BOT_TOKEN="توکن_ربات_شما"
export GITHUB_TOKEN="توکن_گیت‌هاب"
export ADMIN_ID="آیدی_عددی_شما"

# ۴. اجرا
python main.py
